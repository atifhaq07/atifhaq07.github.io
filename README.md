# Deal analysis portfolio

Static site. No build step.

## Publish on GitHub Pages (free, about 5 minutes)
1. Create a public repository named `<your-github-username>.github.io`.
2. Upload the five files in this folder (no subfolders needed).
3. In the repository: Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. After a minute the site is live at `https://<your-github-username>.github.io`.
5. Add that link to your CV header next to LinkedIn.

Files:
- `index.html` home page
- `spectris.html` the case study
- `Spectris_KKR_LBO_Case_Study.xlsx` the model
- `Spectris_KKR_report.pdf` the report
